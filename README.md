# ProFinder CI 🔍👷

**Find Trusted Professionals Near You in Côte d'Ivoire**

ProFinder CI is a professional marketplace platform that connects individuals and companies with verified, competent workers across multiple sectors.

> Our Commitment: "Proposer des profils sérieux, compétents et adaptés aux besoins des entreprises et des particuliers."

### 🌍 Live Demo
`https://profinder-ci.netlify.app` (replace with your link after deployment)

### ✨ Features

**For Visitors:**
- Browse 60+ professional profiles organized in 6 categories
- Smart search - Find any profession in 2 seconds
- One-click WhatsApp contact
- French / English language toggle (FR / EN)

**Client Dashboard - "I Need a Service":**
- Post a request for any professional
- Select profession, city, budget, duration
- Auto-share request directly to WhatsApp for fast response
- Cities supported: Grand-Bassam, Abidjan, and all CI

**Worker Dashboard - "I Offer a Service":**
- Create professional profile in 1 minute
- Add name, city, profession, daily rate, WhatsApp
- Appear instantly in Live Professionals list
- Receive direct client requests on WhatsApp

### 📂 Categories Covered
1. **Automobile & Maintenance** - Mechanic, Electrician, Painter, Car Washer...
2. **Building & Construction** - Mason, Plumber, Electrician, Carpenter, Welder...
3. **Restaurant & Hotel** - Cook, Baker, Waiter, Housekeeping...
4. **Home Services** - Cleaner, House Help, Nanny, Gardener, Security, Driver
5. **Commerce & Administration** - Sales, Secretary, Accountant, Storekeeper
6. **Technical & Industry** - Maintenance Technician, Machine Operator...

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **No Framework** - Lightweight and fast for mobile users in CI
- **Integration:** WhatsApp API (`wa.me`) for direct messaging
- **Hosting:** Netlify / Vercel / GitHub Pages compatible
- **Responsive:** Mobile-first design
